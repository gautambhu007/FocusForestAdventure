# Word Hunt — art contract

How painted art gets into the game, one sheet at a time, without a code
change. Everything below is enforced by `WordSearchArtTests`; the names are
generated by `WordSearchArt` in `Features/WordSearch/WordSearchArt.swift`.

## The three layers

Each sheet's page is three independent layers. Each has a fallback that ships
today, and each is replaced by adding an **image set with exactly this name**
to `Resources/Assets.xcassets`. Nothing else is edited.

| Layer | Asset name | Today's fallback | Notes |
|---|---|---|---|
| Mascot pose | `WS_CHAR_<nn>_<State>` | the sheet's emoji, moved per state | `<nn>` is the two-digit sheet number. If only `_Idle` exists it is shown in every state |
| Scene | `WS_ENV_<nn>` | a painted forest place for 21 sheets (see table), the palette's gradient for the rest | Drawn `scaledToFill` behind the whole page with a 25% cream wash for legibility |
| Word picture | `WS_WORD_<WORD>` | the word's emoji | Shown at 28×28pt beside the word in WORDS TO FIND |

### Mascot states (brief §13)

`Idle` `Look` `Point` `WordFound` `Happy` `Celebrate` `Encourage` `Hint`

The game drives them from play: **Idle** at rest, **Hint** while a hinted
letter is lit, **WordFound** for ~0.6s after a find, **Encourage** for ~0.35s
after a drag that is not a word, **Celebrate** on the completion card.
`Look`, `Point` and `Happy` are reserved for art that has them; the game does
not request them yet.

Deliver a state as a still PNG image set (1×/2×/3×). The loader reads image
sets only for now; Lottie poses (a breathing `Idle`, a `Celebrate` loop) need
a loader change and are not part of this contract yet. Transparent background, no baked shadow, character facing the grid (it sits
at the panel's top-right corner, overlapping the edge). Design height ≈ 60pt
on the panel, 84pt on the completion card.

### Scenes

Portrait 1290×2796 and landscape 2796×1290 (or one square 2796² that crops
well both ways). The puzzle panel covers the middle, so the interesting
detail belongs in the margins — brief §12: frame the puzzle, don't compete.

### Word pictures

Square, transparent, one object, readable at 28pt. The picture *is* the clue
for a four-year-old (brief §9): 🐝 BEE, not BEE.
