# MASTER FLORA PROMPT
## 40 Original Children's Word Search Worksheets
### Ages 4–7 • iPhone + iPad • Unity 3D • Animated Characters

Create a complete collection of **40 unique, highly attractive children's Word Search worksheets/screens** for a premium educational game for children aged **4–7**.

The attached **Flora Word Search** and **Fauna Word Search** images are provided ONLY as visual references for the overall page composition and children's worksheet design.

Do NOT copy their artwork, characters, illustrations, exact typography, wording, puzzle content, or exact layouts.

Instead, understand their **design logic** and create a completely original visual system.

---

# 1. PRIMARY OBJECTIVE

Create **40 separate Word Search worksheets**.

Each worksheet must feel like a unique illustrated children's adventure page.

Every worksheet must contain:

1. Unique theme
2. Unique title
3. Unique target words
4. Unique puzzle arrangement
5. Unique supporting illustrations
6. Unique character/environment combination
7. Unique decorative composition
8. Unique color treatment appropriate to its theme
9. Independent character animation opportunities
10. Unity/iOS-friendly layered assets

The worksheets should look like they belong to the **same premium game**, but no two worksheets should feel visually repetitive.

---

# 2. MOST IMPORTANT RULE — ZERO WORD REPETITION

This is a strict global rule.

### NO TARGET WORD MAY APPEAR MORE THAN ONCE ACROSS ALL 40 WORKSHEETS.

Create a global word database before designing the worksheets.

If a word is used in Worksheet 1, it is permanently unavailable for Worksheets 2–40.

Do not reuse:
- singular words
- plural versions of the same word
- obvious grammatical variations
- hyphenated versions
- alternate spellings
- extremely obvious derivatives

If BUTTERFLY is used, do not later use BUTTERFLIES as a workaround.

---

# 3. WORD DATABASE REQUIREMENT

Create at least **400 age-appropriate candidate words** before selecting the final words.

Then select approximately:

**8 unique words × 40 worksheets = 320 unique target words**

Maintain a global uniqueness table.

Every selected word must have:

- worksheet number
- theme
- word
- word length
- difficulty
- illustration association

Before final output, perform a **global duplicate check**.

If any target word appears twice, replace the duplicate with a completely unused word.

# 15. WORD FOUND ANIMATION

When a child successfully finds a word:

1. Selected letters gently scale up.
2. Selection highlight animates.
3. Word list item becomes completed.
4. Matching illustration reacts.
5. Character reacts.
6. Small sparkle/particle effect appears.
7. Short positive sound hook plays.

Total animation:

**approximately 0.5–1.0 seconds**

Do not interrupt the child's flow.
